# Sole Street - Sneaker Selling Store

A simple sneaker selling website made for AAT-1 Full Stack Web Development.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser LocalStorage

## Pages
1. Landing Page - `index.html`
2. Product Display Page - `products.html`
3. Shopping Cart - `cart.html`
4. Payment Page - `payment.html`

## Features
- Responsive layout
- Product listing
- Add to cart
- Increase/decrease quantity
- Remove products
- Cart data saved using LocalStorage
- Payment form validation
- Navigation between pages

## How to Run
Open `index.html` in a browser.
